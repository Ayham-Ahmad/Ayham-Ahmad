## 🚀 Featured Projects

### Smart Financial Advisory System (SFAv2) — *Multi-Tenant AI Analytics Platform*
[![SFAv2](https://img.shields.io/badge/SFAv2-272B36?style=for-the-badge&logo=github&logoColor=white)](https://github.com/Ayham-Ahmad/SFAv2)

> Connect your databases. Ask questions in plain language. Get charts and answers in real time.

- Multi-tenant AI analytics platform: companies plug in their own databases (MySQL, PostgreSQL, MongoDB, SQLite, CSV, Excel) and query them through an AI agent using natural language.
- **Multi-stage agentic pipeline**: intent classification → planner → table selection → SQL/MongoDB generation → safety validation → query execution → numeric verification → formatting.
- **RAG** for context-aware financial analysis (LangChain + ChromaDB).
- Real-time streaming via **Server-Sent Events** with 12+ interactive chart types.
- Role-based access control, per-company data isolation, and encryption-at-rest.
- Multi-LLM support: Groq, DeepSeek, and OpenAI with automatic failover.

### udemyCrawl — *Large-Scale Udemy Course Crawler*
[![udemyCrawl](https://img.shields.io/badge/udemyCrawl-272B36?style=for-the-badge&logo=github&logoColor=white)](https://github.com/Ayham-Ahmad/udemyCrawl)

- Two-stage asynchronous Python crawler that collected structured data for **95,000+ unique Udemy course listings** across 11 main categories.
- **Stage 1** discovers and paginates category URLs (Crawl4AI), **Stage 2** extracts full course details (title, objectives, content, requirements, description, target audience) with Playwright stealth + rotating user agents.
- Concurrency-limited parallel crawling, duplicate detection, and resumable checkpoints (`done_crawling.json`).
